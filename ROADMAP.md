# Product Roadmap

## Product vision

**Upload data. Understand it in seconds.**

The product is designed for freelancers, small businesses and
consultants who need a useful business dashboard without a complex
BI implementation.

## Milestone 1 — Smart foundation

- [x] CSV upload
- [x] KPI dashboard
- [x] Data analysis
- [x] Data-quality report
- [x] Smart column-role detection
- [x] Confidence scores and explanations
- [x] Downloadable dashboard configuration
- [ ] Data Quality Score
- [ ] Rule-based executive summary
- [ ] Automatic KPI selection
- [ ] Automatic chart selection

## Milestone 2 — Reporting

- [ ] Saved configuration upload
- [ ] PDF executive report
- [ ] Excel export
- [ ] Branding and logo upload
- [ ] Light, dark and corporate themes

## Milestone 3 — AI assistance

- [ ] Optional LLM-written summary
- [ ] Ask-your-data assistant
- [ ] Recommendation generation
- [ ] Cost and privacy controls
