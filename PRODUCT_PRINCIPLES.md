# Product Principles

1. **Zero configuration first**  
   Detect useful defaults automatically and let users override them.

2. **Explain everything**  
   Every automated choice should include a clear reason.

3. **Business first**  
   Prefer useful decisions and summaries over decorative charts.

4. **Beautiful by default**  
   The dashboard should look professional without manual styling.

5. **Modern code only**  
   Use current Streamlit APIs, modular Python, type hints and tests.

6. **Privacy-conscious architecture**  
   Core analytics must work without uploading data to an external AI
   service.
