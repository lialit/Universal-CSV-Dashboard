# Universal CSV Dashboard — Brand Book

## Brand idea

Universal CSV Dashboard turns an ordinary data export into a clear business
view in under a minute.

**Primary promise:** Understand your business in under 60 seconds.

**Supporting message:** A time-saving analytics assistant with a user-friendly
experience.

## Visual character

The brand should feel calm, clear, capable and approachable. It uses the visual
language of a modern executive dashboard: generous whitespace, restrained
colour, rounded cards and one dominant data colour per chart.

## Logo

- `assets/brand/logo-horizontal.svg` — primary lockup
- `assets/brand/logo-mark.svg` — compact mark
- `assets/brand/favicon.svg` — browser/app icon

Keep clear space around the mark equal to one quarter of its height. Do not
stretch, rotate, recolour individual parts or place the logo on a busy image.

## Colour system

| Role | Hex | Use |
|---|---:|---|
| Primary blue | `#2563EB` | Links, actions, primary charts |
| Turquoise | `#14B8A6` | Secondary accent and positive flow |
| Deep navy | `#10213D` | Headings and primary text |
| Muted text | `#667085` | Supporting copy |
| Border | `#D7DEE8` | Card and divider lines |
| Background | `#F5F7FA` | Page background |
| Success | `#16A34A` | Positive states |
| Warning | `#F97316` | Attention states |
| Purple | `#7C3AED` | Rare secondary category |

Avoid rainbow palettes. A chart should normally use one dominant series colour,
with semantic colours reserved for meaning.

## Typography

Use **Inter** where available. Use **Segoe UI**, **Roboto**, **Arial** or
**DejaVu Sans** as fallbacks.

| Element | Size | Weight |
|---|---:|---:|
| Product hero | 48–72 px | Bold |
| Page title | 28–32 px | Bold |
| Section title | 16–20 px | Semibold |
| KPI | 28–34 px | Bold |
| Body and labels | 12–16 px | Regular |
| Chart labels | 10–12 px | Regular |

## UI language

- White cards on a cool light-grey background
- 12 px corner radius for dashboard cards
- Light borders and subtle shadows
- Spacing based on 8, 12, 16, 20, 24 and 32 px
- Clear data labels; decoration never competes with information

## Illustration and photography

Use clean data flows, chart cards and document motifs. The visual focus should
be understanding, not complexity. Avoid screenshots filled with browser chrome,
tiny unreadable UI, people posing with laptops, neon gradients and decorative
data that looks random.

## Screenshot standard

1. Use the light application theme.
2. Capture the full content area at a consistent desktop width.
3. Hide personal browser information and local paths.
4. Use realistic, non-sensitive sample data.
5. Crop consistently and keep the same zoom level.
6. Prefer one explanatory caption below each image.

## Voice

Write in clear, direct English. Lead with the user's outcome. Prefer
“Upload a CSV and see the answer” to technical implementation language.
Never promise AI, export formats or connectors before they are available.
