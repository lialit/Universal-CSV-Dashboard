# Example Datasets

These small, synthetic CSV files demonstrate the supported first-pass
analysis across common business contexts. They contain no real customer or
company data.

Ready-to-use examples:

- sales.csv
- ecommerce.csv
- inventory.csv
- marketing.csv
- finance.csv

Upload any file through **Upload & Configure**. Each example contains a date,
a primary numeric metric and a category that the Smart Detection Engine can
identify and that the user can correct before analysis.

The domain folders contain matching sample files plus contextual notes. The
root-level files are convenient for quick manual and release validation.
