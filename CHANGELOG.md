# Changelog

All notable product changes are documented here.

## [0.2.0] — Smart Detection

### Added

- Automatic date-column detection
- Automatic primary-metric detection
- Automatic category and identifier detection
- Boolean and text-column recognition
- Confidence scores and human-readable explanations
- Smart defaults in the upload configuration page
- Downloadable `dashboard_config.json`
- Unit tests for the detection engine
- Product roadmap

## [0.1.0] — Initial Product

### Added

- CSV upload
- Multipage Streamlit dashboard
- KPI cards
- Time-series and category charts
- Distribution and correlation analysis
- Missing-value and duplicate reporting
- Cleaned CSV export
