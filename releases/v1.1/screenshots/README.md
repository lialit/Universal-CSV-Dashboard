## Capture standard

- Use the bundled synthetic demo dataset.
- Use the light theme.
- Keep the sidebar visible so navigation is clear.
- Prefer a desktop viewport near 1440×900 or wider with readable content.
- Do not include customer data, local filesystem paths, credentials or private account information.
- Browser chrome should be excluded when possible.
