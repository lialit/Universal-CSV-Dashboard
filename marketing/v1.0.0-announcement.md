# Universal CSV Dashboard 1.0.0 — Announcement Copy

## Product announcement

Universal CSV Dashboard `1.0.0` is now available.

It is a local-first Streamlit application that turns a CSV into an editable,
evidence-linked business overview without sending the data to an external AI
or analytics service.

The first stable release includes automatic field detection, executive
metrics, transparent data-quality scoring, evidence-linked Business Insights,
local guided explanations, saved projects and branded Excel/PDF reports.

The validated upload boundary is 25 MB. The release passed 176 automated tests,
strict dependency and privacy checks, representative business-example testing
and the complete release-readiness gate.

Repository and release:
https://github.com/lialit/Universal-CSV-Dashboard/releases/tag/v1.0.0
