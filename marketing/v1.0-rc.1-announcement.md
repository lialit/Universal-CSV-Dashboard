# Universal CSV Dashboard 1.0.0-rc.1 — Announcement Copy

## LinkedIn / Product update

Universal CSV Dashboard has reached `1.0.0-rc.1`.

It is a local-first Streamlit application that turns a CSV file into an
editable, evidence-linked business overview — without sending the data to an
external AI or analytics service.

The release candidate includes automatic field detection, executive metrics,
Business Insights, a transparent Data Quality Score, local guided
explanations, saved projects and branded Excel/PDF exports.

The validated v1.0 boundary is 25 MB per CSV. A 24 MB synthetic reference file
with 738,965 rows completed core analysis in 4.07 seconds on the Windows Python
3.11 test environment, and repeated page visits were immediate after the
session results were prepared.

This is a release candidate, so feedback and reproducible bug reports are very
welcome.

Repository: https://github.com/lialit/Universal-CSV-Dashboard

The first public release candidate is focused on trust and repeatability rather
than adding more features. Upload a supported CSV, review the detected fields,

- installation on a clean Python 3.11 environment;
- field suggestions for different business datasets;
